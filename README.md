# 과제 09: 모든 정점 쌍의 최단경로 탐색

## 1. 파일 구성 및 실행

- `main.c`: 그래프 생성, 그래프 출력, Floyd-Warshall 알고리즘, 최단경로 복원, 결과 검증을 구현한 단일 소스 파일이다.

## 2. 그래프 생성 방법

정점 10개(0~9), 간선 20개인 가중치 무방향 단순 그래프를 인접 행렬로 표현하였다. 간선이 없으면 0을 저장하고, 간선이 있으면 1~100의 가중치를 대칭 위치에 저장한다. 가중치는 항상 1 이상이므로 0을 "간선 없음"의 표시로 사용할 수 있다.

먼저 정점 1~9를 각각 자신보다 번호가 작은 정점 하나와 연결하여 9개의 간선으로 이루어진 트리를 만든다. 이후 자기 루프와 중복 간선을 제외하면서 11개의 간선을 추가한다. 트리가 이미 모든 정점을 연결하므로 그래프는 항상 연결 그래프이고, 간선 수는 정확히 20개가 된다.

이 방식은 가능한 모든 연결 그래프를 균등하게 생성하지는 않는다. 다만 과제의 조건(정점 10개, 간선 20개, 단순 그래프, 연결 그래프)은 항상 만족한다.

## 3. 최단경로 계산 및 복원

모든 정점 쌍의 최단거리는 Floyd-Warshall 알고리즘으로 계산하였다. `dist[i][j]`는 현재까지 구한 최단거리이고, `next[i][j]`는 i에서 j로 가는 경로에서 바로 다음에 방문할 정점이다.

중간 정점 k를 거치는 거리 `dist[i][k] + dist[k][j]`가 기존 거리보다 작으면 거리를 갱신하고 `next[i][j] = next[i][k]`로 설정한다. i에서 j로 가는 경로의 첫 걸음은 i에서 k로 가는 경로의 첫 걸음과 같기 때문이다. 출발 정점부터 `next[current][destination]`을 목적지에 도달할 때까지 반복해서 따라가며 실제 경로를 출력한다.

비교에 `<`를 사용하므로, 거리가 같은 경로가 여러 개이면 먼저 찾은 경로를 유지한다. 무방향 그래프이므로 u < v인 경우만 출력하여 총 10 × 9 ÷ 2 = 45쌍을 처리한다. 시간 복잡도는 O(V³), 공간 복잡도는 O(V²)이다. V = 10으로 매우 작으므로 Floyd-Warshall이 구현이 간단하고 충분히 빠르다.

## 4. 결과 검증

`verifyPaths` 함수는 복원한 경로를 따라가며 원래 그래프의 간선 가중치(`graph[a][b]`)를 직접 더한 뒤, 그 합이 `dist[u][v]`와 같은지 비교한다. `dist` 값을 다시 `dist`와 비교하는 것이 아니라 원본 간선 가중치로 합을 계산하므로 Floyd-Warshall의 결과와 독립적인 검증이다. 경로가 존재하지 않는 간선을 지나거나 목적지에 도달하지 못하면 불일치로 처리한다.

## 5. 실행 결과 분석

출력에서 정점 10개와 서로 다른 간선 20개를 확인하였다. 모든 간선의 가중치는 1~100 범위이며, 자기 루프와 중복 간선은 없었다. 모든 정점 쌍에 대해 경로가 출력되었고(`No path`가 없으므로 연결 그래프임을 확인), 마지막에 `Total vertex pairs : 45`가 표시되었다. 또한 `Verified : 45/45 pairs OK`가 출력되어 45개 쌍 모두에서 경로의 가중치 합과 최단거리가 일치함을 확인하였다.

대표적인 결과는 다음과 같다.

| 정점 쌍 | 최단경로 | 최단거리 |
|---|---|---|
| 0 → 3 | 0 → 3 | 3 |
| 0 → 6 | 0 → 3 → 4 → 6 | 83 |
| 1 → 5 | 1 → 2 → 5 | 19 |
| 2 → 3 | 2 → 1 → 3 | 59 |
| 8 → 9 | 8 → 7 → 1 → 9 | 147 |

직접 연결된 간선이 있어도 그것이 최단경로가 아닌 경우가 있었다.

- 정점 0과 6 사이의 직접 간선 가중치는 96이지만, 0 → 3 → 4 → 6의 비용은 3 + 49 + 31 = 83이다.
- 정점 1과 5 사이의 직접 간선 가중치는 43이지만, 1 → 2 → 5의 비용은 8 + 11 = 19이다.
- 정점 2와 3 사이의 직접 간선 가중치는 85이지만, 2 → 1 → 3의 비용은 8 + 51 = 59이다.

세 경우 모두 간선을 더 많이 거치는 경로가 직접 간선보다 짧다. 이를 통해 간선 수가 아니라 가중치의 합을 기준으로 최단경로를 구했음을 확인할 수 있다.

가장 먼 정점 쌍은 8 → 9이며, 8 → 7 → 1 → 9 경로의 비용은 27 + 39 + 81 = 147이다.
